Coach

The coach runs on Claude through your own Anthropic API key. It's billed to you per use — usually pennies per conversation — and the key is stored only on this phone.

  1. On a computer, go to console.anthropic.com and sign in.
  2. Add a payment method under Billing and buy a small amount of credit ($5 is plenty to start).
  3. Go to API Keys → Create Key, name it "Field Sales", and copy it.
  4. Paste it below. Texting it to yourself is the easiest way to get it onto your phone — delete the text after.
